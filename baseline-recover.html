Recover a Baseline

A baseline is saved to this browser the moment it finishes, before anything is sent anywhere. If a screener was sat while the sheet sync was down — or before the page was gated, so it filed under “guest” — the result is still here. It just never went up. This finds it and sends it.

Nothing here?

A baseline lives in the browser it was sat in. It will not appear if this is a different browser or device, if private/incognito mode was used, or if site data has been cleared. Try the same browser on the same machine, signed in as the same student.
